# Лабораторна робота № 12

**Тема:** Програмна реалізація абстрактних типів даних.

**Мета:** Набуття ґрунтовних вмінь і практичних навичок об'єктного аналізу й проєктування, створення класів С++ та тестування їх екземплярів, використання препроцесорних директив, макросів і макрооператорів під час реалізації програмних засобів у кросплатформовому середовищі Code::Blocks.

**Завдання:**
1. Як складову заголовкового файлу `Modules_Bureiko.h` розробити клас `ClassLab12_Bureiko` - формальне представлення абстракції сутності предметної області (об'єкта) за варіантом, поведінка об'єкта якого реалізовує розв'язування задачі 12.1.
2. Реалізувати додаток `Teacher`, який видає 100 звукових сигналів і в текстовий файл `TestResults.txt` записує рядок *"Встановлені вимоги порядку виконання лабораторної роботи порушено!"*, якщо файл проєкту `main.cpp` під час його компіляції знаходився не в `\Lab12\prj`, інакше створює об'єкт класу `ClassLab12_Bureiko` із заголовкового файлу `Modules_Bureiko.h` та виконує його unit-тестування за тест-сьютами із `\Lab12\TestSuite\`, протоколюючи результати тестування в текстовий файл `\Lab12\TestSuite\TestResults.txt`.

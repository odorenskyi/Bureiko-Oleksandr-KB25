# Аналіз та об'єктно-орієнтоване проєктування (Лабораторна робота №12, Варіант 14)

## 1. Концептуалізація та об'єктний аналіз предметної області
* **Предметна область:** Геометричні тіла та просторові сутності.
* **Сутність (об'єкт):** Кубик Рубіка (формалізований як Куб).
* **Абстрагування:** Для розв'язання задачі обчислення площі поверхні геометричної сутності відкидаються несуттєві властивості (колір граней, внутрішній механізм обертання, матеріал) і виділяються лише математичні та структуровані характеристики.
  * **Атрибути (стан):** Довжина грані куба (a).
  * **Поведінка (інтерфейс):** Ініціалізація початкового стану, надання поточних значень атрибутів (гетер), безпечна зміна значення атрибутів з валідацією (сетер), обчислення площі поверхні.

**Постановка задачі 12.1:** Створити абстрактний тип даних (клас) `ClassLab12_Bureiko`, який представляє куб, інкапсулює його єдиний атрибут (довжину грані) та забезпечує обчислення площі поверхні за формулою:
S = 6a^2
де S - площа поверхні, a - довжина грані куба.

## 2. Аналіз вимог до програмного модуля (класу C++)
* **Функціональні вимоги:**
  * Забезпечити початкову ініціалізацію атрибутів через конструктор.
  * Надати можливість зчитування поточного значення довжини грані.
  * Реалізувати функцію обчислення площі поверхні куба.
* **Нефункциональні вимоги / Валідація даних:**
  * Довжина грані куба обов'язково має бути строго більшою за нуль (a > 0).
  * Спроба встановити некоректне (від'ємне або нульове) значення має відхилятися системою з поверненням прапорця помилки.
* **Вимоги безпеки (Інкапсуляція):**
  * Всі дані-члени класу повинні бути прихованими (`private`), щоб унеможливити прямий несанкціонований доступ або випадкове пошкодження стану об'єкта.
  * Доступ до стану об'єкта дозволяється виключно через публічний інтерфейс (`public`).

## 3. Архітектура програмного модуля
* **Компонентна структура:** Клас інтегрується у вже існуючу структуру індивідуальних модулів розробника. Оголошення опису класу розміщується у заголовковому файлі `Modules_Bureiko.h`, а детальна реалізація його методів - у файлі вихідного коду `Modules_Bureiko.cpp`.
* **Зв'язність:** Висока внутрішня зв'язність за рахунок того, що всі методи класу працюють виключно над інкапсульованим атрибутом довжини грані куба.

## 4. Детальне проєктування (Специфікація ADT)
Абстрактний тип даних представлено класом `ClassLab12_Bureiko`.

### Специфікація членів класу:
* **Private:**
  * `double edge_length;` - змінна для зберігання дійсного значення довжини грані куба.
* **Public:**
  * `ClassLab12_Bureiko(double a = 0.0);` - конструктор з параметром за замовчуванням. Якщо передане значення a \le 0, ініціалізує грань базовим значенням `0.0`.
  * `bool set_edge(double a);` - функція-мутатор (сетер). Перевіряє умову a > 0. Якщо умова виконується, оновлює `edge_length` і повертає `true`. Інакше стан об'єкта не змінюється, функція повертає `false`.
  * `double get_edge();` - функція-аксесор (гетер). Повертає поточне значення `edge_length`.
  * `double calculate_surface_area();` - метод обчислення площі поверхні. Повертає результат виразу `6.0 * pow(edge_length, 2)`.

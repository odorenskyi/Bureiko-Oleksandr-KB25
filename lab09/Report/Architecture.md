ЗАДАЧА 9.1: Розрахунок вартості спожитої електроенергії

1. Постановка задачі: Необхідно обчислити суму до сплати за електроенергію на основі диференційованої тарифної сітки залежно від обсягу споживання.

2. Вхідні дані:
kwh (тип double) - кількість спожитої за місяць електроенергії (кВт·год).

3. Вихідні дані:
Результат виконання функції (тип double) - сума до сплати у гривнях.

4. Алгоритм та конструкція функції:
- Функція матиме прототип: double calc_electricity_cost(double kwh);
- Застосовується оператор розгалуження if-else if-else для визначення тарифної зони:

* Якщо kwh <= 150, тариф = 0.3084 грн. Вартість = kwh * 0.3084.

* Якщо kwh > 150 та kwh <= 800, тариф = 0.4194 грн. Обчислення здійснюється з урахуванням базового обсягу: (150 * 0.3084) + ((kwh - 150) * 0.4194).

* Якщо kwh > 800, тариф = 1.3404 грн. Формула: (150 * 0.3084) + (650 * 0.4194) + ((kwh - 800) * 1.3404).
- Обчислене значення повертається з функції за допомогою return.

ЗАДАЧА 9.2: Визначення найменшої швидкості вітру за шкалою Бофорта

1. Постановка задачі:
З шести зафіксованих показників швидкості вітру (м/с) знайти мінімальний та перевести його у бали за шкалою Бофорта.

2. Вхідні дані:
6 параметрів (тип double) — швидкості переміщення повітряних мас: v1, v2, v3, v4, v5, v6 (відповідають часу 00:00, 04:00, 08:00, 12:00, 16:00, 20:00).

3. Вихідні дані:
Результат виконання функції (тип int) — бал від 0 до 12 за шкалою Бофорта.

4. Алгоритм та конструкція функції:
- Функція матиме прототип: int get_min_beaufort(double v1, double v2, double v3, double v4, double v5, double v6);
- За допомогою вбудованої функції std::min (з бібліотеки <algorithm>) або послідовних порівнянь знаходиться мінімальне значення з шести: min_v.
- Застосовується каскад умов if-else if для порівняння знайденого min_v з діапазонами шкали Бофорта:

* < 0.3 повертає 0

* >= 0.3 та <= 1.5 повертає 1

* >= 1.6 та <= 3.4 повертає 2 і так далі до min_v >= 32.7, що повертає 12.

ЗАДАЧА 9.3: Побітовий аналіз числа

1. Постановка задачі:
Перевірити стан 9-го біта заданого натурального числа. Якщо він дорівнює 1, порахувати загальну кількість нулів у двійковому представленні числа, інакше — кількість одиниць. Під час підрахунку використати тернарний оператор ? :.

2. Вхідні дані:
N (тип unsigned int) — натуральне число в межах від 0 до 500700.

3. Вихідні дані:
Результат виконання функції (тип int) — кількість двійкових нулів або одиниць.

4. Алгоритм та конструкція функції:
- Функція матиме прототип: int count_bits_by_condition(unsigned int N);
- Визначення стану 9-го біта: використання побітового зсуву та логічного "І": bool bit_9 = (N >> 9) & 1;
- Ініціалізація лічильника int count = 0;
- Організація циклу while (N > 0) (або do-while для обробки нуля), де на кожній ітерації перевіряється молодший біт: int current_bit = N & 1;
- Використання тернарного оператора:

* count += (bit_9 == 1) ? (current_bit == 0 ? 1 : 0) : (current_bit == 1 ? 1 : 0);

* (Тобто: якщо 9-й біт = 1, додаємо 1 до лічильника, якщо поточний біт 0. Інакше — якщо поточний 1).
- Побітовий зсув числа вправо на 1 розряд: N >>= 1;
- Після завершення циклу повернення значення count.

ЗАДАЧА 9.4: Інтерактивне консольне застосування

1. Постановка задачі:
- Розробити консольну програму (застосунок), яка надає користувачеві текстове меню для виклику функцій розв'язання задач 8.1, 9.1, 9.2 та 9.3, що містяться у створеній статичній бібліотеці libModules_Bureiko.a. Програма повинна працювати циклічно, обробляти помилкове введення за допомогою звукового сигналу та коректно завершувати роботу за визначеними символами.

2. Вхідні дані:
- choice (тип char) - символ для вибору функції з головного меню.
- exit_choice (тип char або string) - символ для перевірки умови виходу з програми.
- Набори параметрів, що запитуються безпосередньо перед викликом відповідних функцій:

* дійсні числа x, y, z (для задачі 8.1);

* дійсне число kwh (для задачі 9.1);

* дійсні числа v1, v2, v3, v4, v5, v6 (для задачі 9.2);

* беззнакове ціле число N (для задачі 9.3).

3. Вихідні дані:
- Текстові підказки (меню, запрошення до введення).
- Результати роботи обраних функцій (числові значення).
- Звуковий сигнал при помилковому введенні символу меню.

4. Алгоритм та конструкція програми:
- На початку функції main() встановлюється кодування консолі (Windows-1251) для підтримки кирилиці та підключається заголовковий файл Modules_Bureiko.h.
- Організовується головний безкінечний цикл while (true).
- Всередині циклу на екран виводиться перелік доступних команд:
* "d" - розрахунок математичного виразу S (задача 8.1).

* "g" - розрахунок тарифу на електроенергію (задача 9.1).

* "h" - конвертація швидкості вітру за шкалою Бофорта (задача 9.2).

* "j" - побітовий аналіз числа (задача 9.3).

- Виконується зчитування символу choice зі стандартного потоку введення cin.
- За допомогою оператора розгалуження switch (choice) виконується відповідний блок коду:

* case 'd': запит на введення трьох чисел, виклик s_calculation(), виведення результату.

* case 'g': запит на введення kwh, виклик calc_electricity_cost(), виведення результату.

* case 'h': запит на введення шести швидкостей, виклик get_min_beaufort(), виведення результату.

* case 'j': запит на введення N, виклик count_bits_by_condition(), виведення результату.

* default: обробка помилкового введення. В консоль виводиться керуючий символ \a (alert) або використовується функція MessageBeep() з Windows API для генерації звукового сигналу, після чого виводиться повідомлення про помилку і цикл починається спочатку (через оператор continue).
- Після успішного виконання обраної функції програма запитує: "Введіть 'k', 'K' або 'к' для виходу, або будь-який інший символ для повторення".
- Відбувається зчитування exit_choice.
- Застосовується оператор if для перевірки умови виходу. Якщо введено символ латиниці k, K або символ кирилиці к, виконується оператор break, що перериває безкінечний цикл і завершує програму.

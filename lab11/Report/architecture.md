## 1. Загальна архітектура даних
Для реалізації бази даних інформаційної системи "Розклад руху автобусів, АС Кропивницький" обрано динамічну структуру даних — **однозв'язний лінійний список**. 
Цей вибір обґрунтовано необхідністю частого додавання та вилучення елементів без необхідності перерозподілу великих блоків пам'яті (як це було б у випадку зі статичними або динамічними масивами).

### Структура вузла (RouteNode)
Описана у спільному заголовковому файлі `struct_type_project_4.h`.
* **Дані:** масиви символів `char[]` для зберігання номера рейсу, маршруту, періодичності та чотирьох часових позначок (відправлення/прибуття). Використання `char[]` замість `std::string` є критичною вимогою для забезпечення подальшої коректної серіалізації даних у бінарний файл суміжними модулями.
* **Вказівник:** `RouteNode* next;` — вказує на наступний елемент у списку.

## 2. Задача 1: Додавання нового рейса до ІС
**Постановка задачі:** Реалізувати програмний модуль для динамічного створення нового запису про автобусний рейс та додавання його в кінець існуючого списку.

* **Вхідні дані:** Вказівник на початок списку `head` (передається за посиланням `*&`, оскільки функція може його змінити, якщо список був порожнім). Дані про рейс вводяться користувачем інтерактивно.
* **Вихідні дані:** Оновлена структура списку в оперативній пам'яті.
* **Прототип функції:** `void add_route(RouteNode*& head);`
* **Алгоритм:**
  1. Виділити динамічну пам'ять для нового вузла за допомогою оператора `new`.
  2. Інтерактивно зчитати значення всіх полів з консолі (використовуючи `cin.getline()` для коректної обробки пробілів у рядках).
  3. Ініціалізувати вказівник нового вузла `next = nullptr`.
  4. Перевірити, чи порожній список (`head == nullptr`). Якщо так — призначити новий вузол як `head`.
  5. Якщо список не порожній, виконати ітерацію до останнього елемента (`while (temp->next != nullptr)`).
  6. Прив'язати новий вузол до кінця списку (`temp->next = newNode`).

## 3. Задача 2: Вилучення заданого рейса з ІС (за номером)
**Постановка задачі:** Знайти запис у динамічній структурі за заданим номером рейсу, коректно переприв'язати вказівники та вивільнити пам'ять, займану цим записом.

* **Вхідні дані:** Вказівник на початок списку `head` (за посиланням `*&`), константний рядок `route_num_to_delete` (номер рейсу для пошуку).
* **Вихідні дані:** Оновлена структура списку, повідомлення про успішне вилучення або відсутність запису.
* **Прототип функції:** `void delete_route(RouteNode*& head, const char* route_num);`
* **Алгоритм:**
  1. Перевірити список на порожнечу. Якщо порожній — вивести повідомлення та завершити роботу.
  2. Перевірити перший елемент списку (`head`). Якщо його номер збігається із заданим (використовується `strcmp`), змістити `head` на наступний елемент (`head = head->next`) та звільнити пам'ять старого `head` оператором `delete`.
  3. Якщо шуканий елемент знаходиться далі, ініціювати обхід списку. Шукати елемент, дивлячись "на один крок вперед" (`current->next->route_number`).
  4. Якщо елемент знайдено, створити тимчасовий вказівник на нього, переприв'язати вказівник поточного елемента в обхід знайденого (`current->next = current->next->next`).
  5. Вивільнити пам'ять вилученого вузла за допомогою `delete`.

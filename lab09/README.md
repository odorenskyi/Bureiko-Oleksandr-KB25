# Лабораторна робота № 9

Тема: РЕАЛІЗАЦІЯ ПРОГРАМНИХ МОДУЛІВ РОЗГАЛУЖЕНИХ ТА ІТЕРАЦІЙНИХ ОБЧИСЛЮВАЛЬНИХ ПРОЦЕСІВ

Мета: Набуття грунтовних вмінь і практичних навичок реалізації технології модульного програмування, застосування операторів С/С++ арифметичних, логічних, побітових операцій, умови, циклів та вибору під час розроблення статичних бібліотек, заголовкових файлів та програмних засобів у кросплатформовому середовищі Code::Blocks.

Завдання:
1. Реалізувати функції розв'язування задач 9.1-9.3 як складових статичної бібліотеки `libModules_Bureiko.a` (проект `Modules_Bureiko`, створений під час виконання лабораторної роботи № 8).
2. Реалізувати програмне забезпечення розв'язування задачі 9.4 на основі функцій статичної бібліотеки `libModules_Bureiko.a`.

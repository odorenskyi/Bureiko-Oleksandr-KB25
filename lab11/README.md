# Лабораторна робота № 11

**Тема:** Командна реалізація програмних засобів оброблення динамічних структур даних та бінарних файлів.

**Мета:** Набуття грунтовних вмінь і практичних навичок командної (колективної) реалізації програмного забезпечення, розроблення функцій оброблення динамічних структур даних, використання стандартних засобів С++ для керування динамічною пам'яттю та бінарними файловими потоками.

**Завдання:**
1. У складі команди ІТ-проєкта (О. Бурейко, Р. Руденко, Я. Примак) розробити програмні модулі оброблення динамічної структури даних для інформаційної системи "Розклад руху автобусів, АС Кропивницький".
2. Реалізувати програмний засіб на основі розроблених командою ІТ-проєкта модулів.

**Варіант №:** 4

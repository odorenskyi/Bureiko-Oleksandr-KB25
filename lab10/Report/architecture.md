# Аналіз та модульна архітектура (Лабораторна робота №10, Варіант 6)

## Загальні вимоги до проектування
- Імена вхідного та/або вихідного файлів передаються у функції як параметри.
- Перед читанням/записом обов'язково реалізується перевірка успішності відкриття файлового потоку (наприклад, метод `is_open()`).
- Після завершення операцій всі відкриті файлові потоки закриваються методом `close()`.
- Для роботи з файлами використовуються об'єкти `ofstream` та `ifstream` з бібліотеки `<fstream>`.

## Задача 10.1: Створення та запис у вихідний файл
**Постановка задачі:** Зчитати речення з вхідного текстового файлу. У новий вихідний файл записати авторську інформацію, кількість знаків оклику та питання у зчитаному реченні, а також саме речення, але без голосних літер.

* **Вхідні дані:** `input_filename` (рядок), `output_filename` (рядок).
* [cite_start]**Вихідні дані:** Створений (або перезаписаний) файл `output_filename`[cite: 213].
* **Прототип функції:** `void process_and_write_10_1(const char* input_filename, const char* output_filename);`
* **Алгоритм:**
  1. Відкрити `input_filename` для читання (`ifstream`).
  2. Зчитати рядок тексту (речення українською мовою). Закрити вхідний файл.
  3. Відкрити `output_filename` для запису (`ofstream`). [cite_start]Старий вміст буде знищено[cite: 213].
  4. Записати у потік авторську інформацію: "Олександр Бурейко, ЦНТУ, Кропивницький, Україна, 2026".
  5. Проітерувати зчитане речення, підрахувати символи `!` та `?`. Записати результати.
  6. Видалити всі голосні літери (а, е, є, и, і, ї, о, у, ю, я) з речення.
  7. Записати модифіковане речення у файл. Закрити потік.

## Задача 10.2: Дозапис транслітерації у вхідний файл
**Постановка задачі:** Зчитати текст із вхідного файлу. До цього ж файлу дописати його транслітеровану версію (відповідно до Постанови КМУ №55) та поточну дату і час.

* **Вхідні дані:** `input_filename` (рядок).
* **Вихідні дані:** Модифікований файл `input_filename` з дозаписаними даними.
* **Прототип функції:** `void append_transliteration_10_2(const char* input_filename);`
* **Алгоритм:**
  1. Відкрити `input_filename` для читання (`ifstream`). Зчитати весь текст у буфер (наприклад, `std::string`). Закрити потік читання.
  2. Виконати транслітерацію зчитаного тексту латиницею.
  3. Отримати локальний час ОС за допомогою функцій `<ctime>` (наприклад, `time` та `localtime` / `asctime`).
  4. [cite_start]Відкрити `input_filename` для дозапису (`ofstream` з прапорцем `ios_base::app` [cite: 201]).
  5. Дописати транслітерований текст та отриманий рядок з датою/часом. Закрити потік.

## Задача 10.3: Обробка числових даних та дозапис
**Постановка задачі:** На основі вхідних числових параметрів виконати обчислення математичної функції з попередньої лабораторної роботи та конвертацію числа. Результати дописати у вихідний файл.

* **Вхідні дані:** `output_filename` (рядок), `x`, `y`, `z` (тип `double`), `b` (тип `unsigned int`).
* **Вихідні дані:** Модифікований файл `output_filename`.
* **Прототип функції:** `void append_calculations_10_3(const char* output_filename, double x, double y, double z, unsigned int b);`
* **Алгоритм:**
  1. Обчислити значення математичного виразу S, викликавши існуючу функцію `s_calculation(x, y, z)`.
  2. Перетворити натуральне число `b` у рядок, що представляє його у двійковому коді (можна використати побітові операції або `std::bitset`).
  3. [cite_start]Відкрити `output_filename` для дозапису (`ofstream` з `ios_base::app` [cite: 201]).
  4. Дописати у файл результати: значення S та двійкове представлення числа `b`. Закрити потік.
